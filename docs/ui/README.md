# UI Design References

This directory holds design references for **Layoutry's own application
UI** — the editor shell, panels, toolbars, and chrome that make up the
product itself.

It is not for anything related to user-generated canvas documents. A
screenshot of the AppHeader or a mockup of the inspector panel belongs
here; a reference for what an _end user's exported page_ might look like
does not — see the styling-rules distinction between Layoutry's own UI and
generated user-document styles in [CLAUDE.md](../../CLAUDE.md).

## What belongs here

- Visual references, mockups, and screenshots that inform how the
  application shell and features should look.
- Short notes tying a reference to the feature or component it informs
  (e.g. which reference guided `components/layout/AppHeader`).

## What does not belong here

- Component API documentation (that belongs next to the component itself).
- User-facing copy/microcopy (not yet given a home; raise it if it becomes
  a real need rather than assuming this directory covers it).
- Anything about styling a user's generated canvas document, as opposed to
  Layoutry's own interface.
