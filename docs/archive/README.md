# Archive

This directory holds documentation that is no longer current but is kept
for historical reference instead of being deleted — for example, a
superseded planning document, a retired report, or notes from an approach
that was tried and abandoned.

## When to archive something

Move a document here when it is replaced by a newer version elsewhere in
`docs/` (a revised roadmap, an ADR that supersedes an earlier one, a report
overtaken by events) and the old content still has value as a record of
what was previously decided or attempted. Do not archive something that
should simply be deleted (e.g. genuinely incorrect or duplicate content
with no historical value) — ask before deleting tracked, user-authored
content either way.

## Convention

- Keep the original filename, or add a date prefix if the name would
  otherwise collide (`2026-07-10-old-roadmap.md`).
- If the document is superseded by a specific newer document, add a short
  note at the top of the archived file linking to its replacement.
- Do not edit archived content to "fix" it retroactively — it is a
  historical record, not living documentation.
