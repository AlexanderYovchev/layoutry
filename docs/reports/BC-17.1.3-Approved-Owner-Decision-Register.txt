3. FINAL QA DECISIONS P-1–P-6 (all approved Option B)
------------------------------------------------------
P-1 Manual conversion of existing Basic Tabs.
    Req existing instances unchanged unless the user converts; new Tabs
    semantic by default from 17.14; an explicit "Convert to Semantic
    Tabs" command preserving appearance, content, compatible styling,
    interactions and accessibility; atomic, undoable; structural
    eligibility with explanations; no automatic migration; legacy
    rendering kept while projects depend on it; N2 requirements for new
    Tabs.
    Arch R1 §13.7 (recognition R1–R6, conversion, insertion), §13.2
    (activation contract — a separate concept). Mx row 47. CP 17.14.
    AC legacy projects open unchanged; conversion keeps computed
    appearance; exact Undo; ineligible structures explained; no invalid
    ARIA. Eng recognition rules; binding replacement; structural roles;
    normalizeTabs.
P-2 Physical AND logical CSS properties (+ direction, writing modes).
    Req physical controls stay; logical properties included; progressive
    disclosure; presentation changes never write the document, convert
    or delete; deterministic conflicts; full contract participation;
    Free-layout geometry investigated.
    Arch R1 §4.10 (+ §5.6, §6.9, §7, §12.5). Mx A2, A1, A5, A12. CP 17.2
    (schema), 17.3 (printing), 17.4 (presentation), 17.7 (completion).
    AC "logical wins inside a rule" in four flow contexts; no document
    write from presentation; Flow resize intent; Free layout unchanged
    and physical. Eng separate twin fields; emission order; Default-only
    direction/writing-mode (LIMIT); Free children LIMIT; explicit
    Convert command (PROPOSED).
P-3 Customizable label number formatting.
    Req precision, locale formatting, grouping, applying to labels only;
    the existing label modes and tokens; consistent per-token formatting;
    the listed edge cases; no double "%"; Design/Preview/Export
    consistency; typed model; no expressions.
    Arch R1 §9.7. Mx A16, row 7. CP 17.13.
    AC identical strings on all surfaces from one editor; fixture matrix;
    stored values unchanged; aria-valuetext. Eng range 0–6 (the owner's
    0–4 was illustrative), defaults, halfExpand + 100% guard, neutral
    locale, compile-time formatting.
P-4 Comprehensive visual CSS counter controls.
    Req named, multiple, reset/increment/set, counter()/counters(),
    nesting, start values, ± increments, predefined styles, prefixes/
    suffixes, pseudo integration and styling; real CSS counter
    behaviour; the listed contracts; safe identifiers; no raw
    expressions; semantics not replaced; @counter-style evaluated
    separately.
    Arch R1 §4.4, §4.11. Mx A14, rows 3, 4, 9–11. CP 17.2, 17.3, 17.4,
    17.6, 17.17.
    AC the 17.6/17.17 acceptance lists. Eng document counter definitions
    with derived identifiers; Default-only operations (LIMIT); same-
    document identity vs foreign name mapping; @counter-style =
    SCOPE-CANDIDATE (not approved, not built, additive later).
P-5 Interrupt playback when editing.
    Req editing never blocked; stop → static → geometry → selection/
    snapping → proceed; the listed operations; unrelated keys don't
    interrupt; save serializes authored state only; all N11 guarantees;
    the blocked-gesture contradiction resolved; overlays/hit targets
    restored.
    Arch R1 §16.1–16.6. Mx A11. CP 17.11.
    AC the 17.11 acceptance list. Eng dedicated playback controller (not
    the one-slot registry), hook points, capture-phase static
    re-targeting, Save does not interrupt.
P-6 Explicit reduced-motion playback override.
    Req reduced motion respected by default; Play / Play as authored /
    Play with reduced motion; the override temporary and Design-only;
    Preview/Export contracts unchanged; the listed edge cases; one
    iteration (N11).
    Arch R1 §16.7, §13.6. Mx A11. CP 17.11.
    AC the 17.11 acceptance list. Eng the globals.css exclusion selector
    (required by the verified !important rule), the exact animation
    reduced-motion contract, the reduced-result hold (PROPOSED).
