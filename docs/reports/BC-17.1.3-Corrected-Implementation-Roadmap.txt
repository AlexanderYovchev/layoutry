0. CHANGES FROM BC-17.1.1 AND MAPPING (BC-17.1.2, kept; still valid)
--------------------------------------------------------------------
The count stays at 25 (BC-17.2–BC-17.26).
- N10.2 names BC-17.23 as the preset checkpoint, so the numbering is
  kept stable.
- Checkpoint boundaries changed in these places:
  - 17.18 ⇄ 17.19 swapped. The SVG MODEL (data, commands, inline defs,
    transforms, clip/mask data) must exist before SVG styling and the
    tools. Old 17.19 "geometry foundation" → new 17.18 "SVG model
    foundation" (expanded); old 17.18 "SVG object styling" → new 17.19.
  - Old 17.21 (advanced vector) loses the vector clipboard and gains
    N3.2 interactive arcs, N4.1 snapping with the grid, and interactive
    clip-geometry editing.
  - Old 17.22 (SVG verification) gains the vector clipboard (N5). Its
    acceptance depends on the same defs, transform and cross-engine
    parity matrix, so building it there avoids a second verification
    pass. The two parts are separately accepted inside the checkpoint.
  - 17.20 gains N3.1 bending, N3.3 conversion, and the lifecycle
    unification (F-SVG-3).
  - 17.2 gains the formatRevision mechanism, the curated compound
    registry schema, inactive-rule semantics and all v4 foundations.
  - 17.5 gains the curated compound-state infrastructure (N6) and the
    outline group.
  - 17.6 gains ::first-line/::first-letter (N7).
  - 17.7 gains logical properties and writing-mode (representation now
    fixed by P-2 and Report 1 §4.10).
  - 17.11 gains N11 playback and the shared asset deduplication utility
    (later reused by 17.19, 17.22, 17.23).
  - 17.13 gains N1.1 (two cards, conversion) and N1.2 (labels).
  - 17.14 gains N2 full semantic Tabs (legacy tabs: manual conversion,
    P-1).
  - 17.15 holds the Pagination revision step (O9).
  - 17.23 absorbs BC-14 (N10.2).
- Mapping (old → new):
  - 17.2–17.17 → same numbers (with the scope changes above);
  - 17.18 SVG styling → 17.19;
  - 17.19 SVG geometry → 17.18 (expanded);
  - 17.20 → 17.20;
  - 17.21 → 17.21 (the clipboard moved out);
  - 17.22 → 17.22 (+ the vector clipboard);
  - 17.23–17.26 → same.

Dependency order:
  17.2 → 17.3 → 17.4 → 17.5 → 17.6
  → {17.7, 17.8 → 17.9, 17.10} → 17.11 (needs 17.10)
  → {17.12 → 17.13, 17.14 → 17.15, 17.16 (needs 17.9–17.11),
     17.17 (needs 17.6, 17.8)}
  SVG: 17.18 (needs 17.3) → 17.19 (needs 17.5, 17.8, 17.9, 17.11)
       → 17.20 → 17.21 (needs 17.10) → 17.22
  Presets: 17.23 (needs 17.7, 17.11) → 17.24 (needs the component
           checkpoints)
  Closure: 17.25 → 17.26
Ordering rationale:
- The asset deduplication utility lands with its first consumer
  (keyframes, 17.11) before SVG (17.19/17.22) and presets (17.23), so
  there is one utility, not three.
- The CSS clipboard is extended in each checkpoint that adds a
  dimension, so no late, incompatible extension is needed.
- SVG definitions are inline values (Report 3 §7.1), so the vector
  clipboard needs no separate definition-remapping architecture.

Testing policy (every checkpoint): change-focused, per the standing
rule. Full suites are never the default. Broader runs are justified
explicitly where listed (17.3, 17.25). The engines are listed per
checkpoint. Electron smoke runs only where the pipeline, media or
storage changes.
