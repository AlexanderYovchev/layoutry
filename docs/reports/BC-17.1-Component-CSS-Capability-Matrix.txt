A. SHARED PROFILE STATUS (applied to the entries in B)
======================================================
The same limits apply to every element because they come from the model,
not the component:
- TYP PARTIAL where supported: 9 fields; missing text-transform,
  word-spacing, text-indent, white-space, text-overflow, wrapping,
  text-shadow, decoration style/colour (M8). CP 17.4b (Typography
  extensions; coordinate with BC-14).
- BG PARTIAL where supported: one colour + one image or one linear/radial
  gradient; missing layers, conic, repeating, origin, clip, blend (M4).
  CP 17.4.
- PAT MISSING everywhere: needs repeating/conic gradients + layers (M4).
  CP 17.4.
- BRD PARTIAL: four sides + four corners FULL; outline/offset MISSING;
  elliptical radii MISSING; border-image MISSING (M9). CP 17.4b.
- SHD: box-shadow FULL (8 layers, inset); text-shadow MISSING (M8).
- OPB PARTIAL: opacity FULL (Filters section); mix-blend-mode,
  isolation, background-blend MISSING (M10). CP 17.10.
- FLT PARTIAL: 8 functions in a fixed order; drop-shadow, backdrop-filter
  and ordering MISSING (M10). CP 17.10.
- MSK: Shape presets (clip-path) PARTIAL on shape-capable containers only;
  free clip-path and masks MISSING (M11). CP 17.10.
- TRF PARTIAL: translate/rotate/uniform scale; skew, origin, perspective
  and 3D MISSING (M7; BC-13 D23 geometry contract). CP 17.10b.
- TRN PARTIAL: one transition among 4 properties (M6). CP 17.3b.
- ANI MISSING (no keyframes) (M5). CP 17.3b.
- PSE ARCH (no selector layer, L1) (M2). CP 17.3.
- ST ARCH (no state rules, L1) (M1). CP 17.3.
- PART: compositions = real child nodes (FULL as nodes; discoverability
  PARTIAL M13); native parts ARCH (M3).
- LAY: display/position/inset/overflow/z-index FULL;
  flex FULL except order (MISSING);
  grid PARTIAL (1–4 column presets; no templates/areas/auto-flow).
- DIM: preferred size/min/max are px-only (PARTIAL: no %/rem/fit-content
  keywords/calc); aspect ratio FULL; box-sizing N/A (fixed border-box by
  design).
- SPC: margin/padding FULL (px numbers, independent and linked); gap FULL
  in flex/grid; logical properties MISSING (low priority).

Profiles:
P-TEXT (h1–h6, p, a, li, button, th, td, legend, figcaption, caption)
  Exposed: Typography, Background, Border, Radius, Box Shadow, Filters,
  Transition, Transform, Display, Position, Spacing, Size (+ Flex/Grid
  child).
  Not exposed: Shape (N/A by design), Layout (N/A for leaves).
  Targets to add: base, before, after, selection; marker (li only).
  States: hover, active, focus-visible (a, button), disabled (button),
  current (a in nav/pagination).
P-CONT (div, section, header, nav, main, article, aside, footer, form,
  label, fieldset, ul, ol, figure)
  Exposed: Background, Border, Radius, Shape (shape-capable tags only;
  N/A for ul/ol/figure/fieldset), Box Shadow, Filters, Transition,
  Transform, Display, Position, Spacing, Layout (Flow/Flex/Grid/Free),
  Size.
  TYP MISSING (inheritable typography on containers: no typography
  resolver in resolveContainerElementStyle → renderer + capability work;
  strongly linked to BC-14 presets). CP 17.4b.
  Targets to add: base, before, after, scrollbar (when overflow scrolls),
  marker (ul/ol via li).
  States: hover, focus-within; open for show/hide targets (interaction
  runtime).
P-MEDIA (img; video; audio; iframe)
  Exposed: Size, Media fit (img/video), Border, Radius, Box Shadow,
  Filters, Transition, Transform, Display, Position, Spacing; Background
  for video/audio/svg (per overrides).
  BG for img N/A by design (covered by the image; Checkpoint 4.3).
  MSK MISSING (no Shape for media: clip-path/mask on an image is a
  common need). CP 17.8.
P-FIELD (input text-like, textarea, select)
  Exposed: Typography, Background, Border, Radius, Box Shadow, Filters,
  Transition, Transform, Display, Position, Spacing, Size, Form Control.
  Targets to add: placeholder (input/textarea); arrow (select, with
  appearance:none).
  States: focus-visible, hover, disabled, invalid/valid, read-only,
  placeholder-shown.
P-TOGGLE (input checkbox/radio)
  Exposed as P-FIELD, but most box styles have little visible effect on
  the native widget (HIDDEN-in-effect: they apply to an element the
  browser paints itself) → PARTIAL in practice.
  Targets: box (appearance:none surface), indicator (::before), label (a
  real sibling node in compositions). States: checked, indeterminate,
  disabled, hover, focus-visible.

  Display/Position).

D. DISABLED PLACEHOLDER CARDS (29) — not components today
=========================================================
- HTML: Menu.
- Components: Panel.
- Layout (all 9): Row, Column, Grid, Grid Item, Wrapper, Section Frame,
  Spacer, Two Column, Stack.
- Media: Gallery, Video Background, Icon.

  Row.

  Spacing Scale, Padding Preset, Shadow, Border Radius, Reset, Typography

- the Styles cards are the obvious home for BC-14 Typography Presets and
  BC-17.11 appearance presets;

  styling);
- Icon depends on SVG work (17.7);
- Video Background depends on media + background layers.
None is implemented in BC-17.1. New components are out of scope (Report
4, O13).

F. CROSS-CUTTING WORK SUMMARY (where each gap is solved)
========================================================
- 17.2 Shared styling architecture: style rules model, capability
  registry, a Canvas stylesheet pipeline (R1–R3), Inspector frame
  (target/state selectors, categories, search). Needed by everything
  below.
- 17.3 States + pseudo-elements on all P-TEXT/P-CONT/P-FIELD
