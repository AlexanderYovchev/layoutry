1. QA CONCERNS FROM THE BRIEF (§6.1–6.10)
-----------------------------------------
Q-6.1 Capability classification, including logical properties
  Finding:
  - BC-17.1.1 marked logical properties and writing-mode N/A only
    because no direction authoring exists. That reasoning was wrong.
  - float, shape-outside and box-sizing were also misfiled.
  Evidence: Report 2 Part D; the type field lists at HEAD.
  Resolution:
  - RESOLVED (reclassified, with checkpoints assigned);
  - the logical-property representation is ODR P-2 (nonblocking,
    BC-17.7);
  - CSS counters are ODR P-4.

Q-6.2 Styling model and target identity
  Finding: needed stable semantic target ids, a native/custom part
  identity, compound/ancestor representation and inactive retention.
  Resolution: ADIP. Report 1 §4–5:
  - global target ids with a kind;
  - shared progress.track/fill across both variants;
  - variant-only parts become inactive;
  - typed examples.

Q-6.3 Cascade and selector generation
  Findings:
  - order alone is insufficient (ancestor/compound specificity);
  - a NEW issue was found during this checkpoint: role-group rules and
    a child's own rules target the same element, so ordering must be
    global (rank buckets), or the migrated Pagination "current" rule
    would lose to the page's base.
  Resolution: ADIP.
  - :where() equalization to (0,1,0) [+ (0,0,1) for pseudo];
  - global rank buckets 0–14 with group-before-own;
  - forced-only interaction atoms on Design;
  - expected computed results tabulated (Report 1 §6.4–6.8).
  UNVERIFIED: :where() and cascade-layer interplay in the three
  engines → BC-17.3 targeted test.

Q-6.4 Shared compiler
  Finding: the Canvas currently mixes Tailwind default classes with
  inline authored styles (34 sites in 26 components).
  Resolution: ADIP.
  - Compiler/printer split; dependency index; failure handling; gesture
    overrides.
  - The update strategy (text chunks vs CSSOM vs per-subtree) is chosen
    by MEASUREMENT in BC-17.3. No speed claim is made.

Q-6.5 v4 and intermediate migration safety
  Finding: BC-17.1.1 keyed the Pagination conversion on "no current
  rule exists". That is unsafe after a user reset.
  Resolution: RESOLVED in architecture.
  - formatRevision inside v4; every schema change = R+1;
  - newer revisions refused;
  - the revision number is the only migration signal;
  - the Pagination step is defined (heterogeneous siblings preserved,
    the five look properties, the unset-equivalent values, a diagnostic
    fallback);
  - protected save for revision upgrades.
  Implementation and fixtures: BC-17.2 / BC-17.15 (ADIP).

Q-6.6 Runtime and accessibility
  Findings:
  - aria-expanded already exists (VERIFIED EXISTING);
  - Basic Tabs are non-semantic and unmarked (VERIFIED EXISTING).
  Resolution: ADIP.
  - The shared runtime-state resolver; semantic Tabs (APG, automatic
    activation); no conflicting ARIA; Canvas simulation without running
    bindings.
  - Legacy tabs = ODR P-1 (BC-17.14).

Q-6.7 SVG reconciliation (N3–N5), pointercancel/Escape
  Finding: F-SVG-3 VERIFIED EXISTING (unsafe):
  - pointercancel commits;
  - Escape restores the whole document;
  - the sessions are not in the active-interaction registry.
  Resolution: ADIP. The unified lifecycle (Report 3 §6) replaces it in
  BC-17.20.
  Also found:
  - F-SVG-1 (a stale comment);
  - F-SVG-2 (the jsdom letterbox fallback);
  - F-SVG-4 (paint is not validated at the schema).
  All are documented, not fixed (restricted checkpoint).

Q-6.8 Presets
  Resolution: ADIP (Report 1 §15).
  - Three libraries; detached application; built-in versioning;
    naming.
  - History boundaries: project-library edits are in project history;
    app-library edits are not.
  - The BC-14 text is missing → action A-4 (blocks BC-17.23 closure
    only).

Q-6.9 Animation playback
  Resolution: ADIP (Report 1 §16).
  - A compile-time Design-only variant (no API mandate);
  - the interruption list; geometry isolation (no store writes; snap
    index refreshed after playback); multiple animations;
    one-iteration semantics.
  - Reduced-motion handling = ENG-PROP, owner-overridable (R-24).

Q-6.10 Browser compatibility
  Resolution: UNVERIFIED by design.
  - Every browser note is classified V1–V5 (Report 2).
  - Per-checkpoint engine plans are in Report 4.
  - No browser test was run in this checkpoint.
