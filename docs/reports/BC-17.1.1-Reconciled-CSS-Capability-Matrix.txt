STATUS CODES
FULL     existing, fully supported (Design, Preview and Export)
PART     existing, partially supported (the gap is named)
HIDDEN   existing in code or export but not authorable
PLAN     missing, planned (a checkpoint is assigned)
BROWSER  browser-limited (included under O15 with a documented limit)
BLOCKED  architecturally blocked by design (reason given)
N/A      not applicable
OWNER    explicitly deferred by an owner decision
UNVER    unverified (needs a browser check at the assigned checkpoint)
(A capability can carry two codes, e.g. PLAN+BROWSER.)

TARGET/STATE SHORTHAND
- Targets: E = element, B/A = ::before/::after, PH = ::placeholder,
  MK = ::marker, SEL = ::selection, BD = ::backdrop, NP = native part,
  RG = role group, ST = structural (nth-child), VO = vector object,
  IP = custom-progress internal part.
- States:
  - S-INT = hover, focus, focus-visible, focus-within, active;
  - S-FORM = checked, indeterminate, invalid, required, read-only,
    placeholder-shown, disabled;
  - S-SEM = current, expanded, open, active-tab;
  - S-ANC = ancestor states (O6).

Real document children versus internal targets:
- Every composition child listed above is a REAL node: selectable,
  styleable with the full Inspector, and part of the Structure tree.
- Internal targets exist ONLY as:
  - pseudo-elements (B/A/PH/MK/SEL/BD);
  - native parts (progress, checkbox/radio, select, search, number);
  - structural targets (table rows/alternate rows, group first/last);
  - role groups (container-scoped styling of a set of real children);
  - vector objects;
  - custom-progress internal parts.
- None of them creates document nodes (O1).

PART D — EXCLUSIONS AND APPROVED DEFERRALS
=========================================
- O8: custom media players / media control styling.
- O13: range, meter, date/time, file, color input, details/summary,
  blockquote, code/pre, description list, tooltip (and their pseudo
  parts such as ::file-selector-button, ::-webkit-slider-thumb, the
  ::details-content marker).
- BLOCKED by design: calc/clamp/var expressions, free-form CSS,
  raw SVG markup, path-data text, :has()-based relationships, arbitrary
  selectors.
- O15 gate failures (Chromium-only): customizable select, the password
  reveal button styling, scrollbar parts in Gecko (Gecko uses the
  standard scrollbar-* properties instead).
- N/A: logical properties and writing-mode (no direction authoring),
  float/shape-outside, view transitions, container/media query
  variants, print styles, performance hints.
