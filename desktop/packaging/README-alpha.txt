WHAT IS LAYOUTRY?
Layoutry is a visual HTML and CSS editor. You build a web page by
dragging elements onto a canvas, arranging them, and styling them with the
Inspector panel on the right, without writing code. This is an early,
private alpha. It is not a finished product, and some features you might
expect, such as saving, are not there yet. Thank you for testing it.


WHAT YOU NEED
- Windows 10 or Windows 11, 64-bit (x64).
- About 400 MB of free disk space.
- Nothing else. Layoutry needs NO installation, NO Node.js, NO web browser,
  NO internet connection and NO developer tools.


HOW TO START LAYOUTRY
1. Right-click the ZIP file you received and choose "Extract All...".
   Extract it to a normal folder, for example Documents or Desktop.
   Do not run Layoutry from inside the ZIP without extracting it first.
2. Open the extracted folder and double-click Layoutry.exe.
   Keep all the other files in the folder next to Layoutry.exe. The app
   needs them.
3. To remove Layoutry later, close it and delete the folder. Nothing else
   is installed.

Layoutry works fully offline. It does not need an internet connection
and does not send anything anywhere. Only images, videos or embedded pages
that YOU point at a web address need the internet to appear.


WINDOWS MAY WARN YOU THE FIRST TIME
This alpha build is not code-signed yet, so Windows does not recognise it.
- Windows SmartScreen may show "Windows protected your PC". If you
  received this build directly from the Layoutry project owner and trust
  it, click "More info" and then "Run anyway".
- Your antivirus may take a moment to scan an unfamiliar program.
Please do not turn off SmartScreen or your antivirus for this. Only run
Layoutry builds you received directly from the project owner.


IMPORTANT: SAVE YOUR WORK
Projects are saved as .layoutry files, wherever you choose:
- File > Save (Ctrl+S) the first time asks where to save. After that it
  saves straight back to the same file.
- File > Save As (Ctrl+Shift+S) saves a separate copy under a new name.
- File > Open File (Ctrl+O) opens a .layoutry file.
- The project name and the file it is saved in are shown at the top.
If another program (or a colleague on a shared folder) changed the file
since you opened it, Layoutry asks before replacing it. Use Save As to
keep both versions.

Layoutry doesn't save for you, but it keeps a recovery copy of unsaved
changes a few seconds after you stop editing (the top bar then says
"Recovery protected"). If Layoutry crashes, is closed by force, or Windows
restarts, it offers that work the next time it starts: Restore, Keep for
Later, or Discard. Restored work is still unsaved, so save it. Changes from
the last few seconds before a crash can still be lost, and recovery copies
are kept on this computer only (in your Layoutry profile folder), so they
are not backups. To keep backups, save .layoutry files and copy them to
another drive or a synced folder.

When you close the window with unsaved changes, Layoutry asks: Save,
Don't Save or Cancel. Don't Save also deletes the recovery copy.

Projects you saved with an earlier alpha (inside Layoutry, before
.layoutry files) are still there: File > Open from Desktop Library.

To open a .layoutry file from Explorer, right-click it and choose
Open with > Choose another app, then browse to Layoutry.exe. You can also
drag a .layoutry file onto Layoutry.exe. (This alpha doesn't install
itself, so it can't register .layoutry files for double-click on its own.)

Reload shortcuts (F5, Ctrl+R) are disabled so they cannot erase your work
by accident. Starting Layoutry a second time just brings the open window
back to the front (and opens the file you started it with, if any).


KNOWN LIMITATIONS OF THIS ALPHA
- No autosave and no exporting of code yet. Recovery copies only cover
  changes up to a few seconds before a crash.
- Double-clicking a .layoutry file doesn't open Layoutry until you choose
  it with "Open with" (see above).
- No installer and no automatic updates: new versions arrive as a new ZIP.
- The editor needs a window at least 900 x 600 pixels inside. On very
  small screens with high display scaling, it may not fit.
- So far tested on one Windows 10 computer at 100% display scaling with a
  single monitor. Windows 11, other scaling levels and multiple monitors
  are exactly what we need your help with.


REPORTING A BUG

Press the Windows key + Shift + S to take one.
